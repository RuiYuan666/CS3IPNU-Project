# CS3IPNU-Project
Real-time Anomaly Detection and Visualization in China's National Carbon Emission Trading 

1. Scraping data
Classify the 2021 transaction data into bulk agreement transactions and listing agreement transactions. Then, perform scenario-based anomaly detection and analysis using both the 3σ rule and the Isolation Forest algorithm.

2. Two algorithms
Apply the 3σ rule and the Isolation Forest algorithm to conduct anomaly detection and analysis on the daily aggregated transaction volumes in the 2021 dataset.

3. Update quota
Be responsible for the real-time update and maintenance of data files. Compare the latest public data from the Shanghai Environment and Energy Exchange with local stock data to identify, supplement, and append missing records, ensuring that the local dataset remains synchronized with the official data at all times.

4. Anomaly detection
Using the 3σ rule and the Isolation Forest algorithm, conduct comprehensive anomaly detection and analysis on the latest transaction data across core metrics including trading volume, turnover, and transaction price.

1. Scraping data：
将2021年交易数据按大宗协议交易、挂牌协议交易分类，同样使用3σ与孤立森林算法，完成分场景的异常检测分析。

2. Two algorithms：
对2021年交易数据中的每日小计交易量，采用3σ与孤立森林两种算法开展异常检测分析。

3. Update quota：
负责数据文件的实时更新维护，通过比对上海环境能源交易所的最新公开数据与本地存量数据，完成缺失数据的比对、补录与追加，保障本地数据文件始终与官方数据保持同步。

4. Anomaly detection：
针对最新交易数据，沿用3σ与孤立森林两种算法，围绕成交量、成交额、交易单价等核心维度，开展全方位的异常检测与数据分析。
